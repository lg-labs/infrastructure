# Requisitos

Para ejecutar la infraestructura necesitas:

## Software

- **Docker** 24+ y **Docker Compose v2**
- **Make** (GNU make)
- **Bash** o **zsh**
- ~8 GB de RAM disponibles si vas a levantar todo (`make all-up`)
- ~20 GB libres en disco para volúmenes

## Sistemas probados

- macOS (Apple Silicon / Intel)
- Linux (Ubuntu, Debian, Fedora)
- Windows con WSL2

## Verificación

```bash
docker --version
docker compose version
make --version
```

Si todo responde correctamente, estás listo para el [Inicio rápido](./quick-start.md).
